This is the GitHub repository for the [Sabotage and Subterfuge](https://steamcommunity.com/sharedfiles/filedetails/?id=3592971803) Crusader Kings 3 mod.

Please check the Releases section to use older versions. Note that I don't develop older versions any further, I just keep them available in case anyone is still playing on an older version of Crusader Kings 3.

If you'd like the current version, I *highly* recommend subscribing to the mod on the Steam Workshop, as per the link above. Feel free to download it from this page if that better suits your purposes.
